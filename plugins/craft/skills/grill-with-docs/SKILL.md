description: A relentless interview to sharpen a plan or design that also settles its glossary terms and ADRs. Use when a grill should also record domain decisions; the caller says where the docs go.

Call the Skill tool twice, for "craft:grilling" and "craft:domain-modeling".

Run the grill rounds from `craft:grilling`. Apply `craft:domain-modeling` to the terms and decisions in each answer. Write the docs where the calling skill says. If the caller says nothing, write them as `craft:domain-modeling` says.
